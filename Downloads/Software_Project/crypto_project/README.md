# Predictive Modeling for Bitcoin Volatility Forecasting

This project is a context-aware Bitcoin volatility forecasting system designed to support short-horizon risk analysis. The system compares price-only and context-aware forecasting workflows using baseline methods, Random Forest, and LSTM models under a chronological evaluation design.

## Current Components
- Data ingestion and validation
- Volatility feature engineering
- Baseline forecasting
- Random Forest forecasting
- LSTM forecasting
- Metric evaluation with RMSE and MAE
- Structured outputs for review and reporting
